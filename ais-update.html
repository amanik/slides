The State Model

  • The Problem: Traditional process mining reconstructs activity flows but lacks a representation of the current operational state of the warehouse
  • The Answer: Represent the warehouse at any moment through activities, flows, and operational metrics like workload, resources, congestion
  • Warehouse State Model: A graph-based representation derived from the process map and enriched with operational metrics

Forms the foundation for prediction, explanation and decision simulation.

Verifiable Goals

  • Task Completion: Checks whether the agent called the required tool
  • Tool Efficiency: Measures tool calls vs. optimal, penalizes redundancy
  • Format Compliance: Validates output is valid JSON with required fields
  • Error Handling: Evaluates recovery from tool failure
  • State Verification: Checks for expected keywords in agent responses
  • Sequence Order: Verifies tools are called in the correct order
  • Constraint Satisfaction: Verifies constraints like maximum number of turns
